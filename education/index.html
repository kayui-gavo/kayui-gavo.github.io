物理教学

把公式还原到原理，把章节连成体系。

力学、波动、电磁学并非彼此割裂。简谐运动可以贯穿弹簧、单摆、浮体与 LC 回路；驻波可以借助三角恒等变换重新推导；周期切换与重复过程，又会自然落到数列与递推。把这些联系讲清楚，学生面对陌生题时才有可能重新建立推理。

校内考真正拉开差距的，往往不是计算量，而是能否从长文中准确提取条件、判断近似、补全中间推导，并把陌生设问转化为熟悉的物理模型。

01｜推导

从公式回到它成立的理由

用微小量、极限与微积分重新理解速度、功与能、电磁感应等关系。结论的来源清楚以后，适用条件与失效边界也随之清楚。

02｜结构

跨章节识别同一种数学结构

把力学、波动和电磁学中反复出现的结构并列起来理解。学生记住的不是孤立题型，而是一组能够在不同情境中重新调用的模型。

03｜记述

把长题拆成条件、模型与推导

先确定研究对象、过程、约束与近似，再选择定律、建立方程、完成结论。训练范围同时覆盖计算、推导与书面说明。

基础准确，判断稳定。

共通考试与 EJU 要求学生准确理解高中物理知识，并能稳定处理计算、实验、图表与文字条件。练习重点放在公式意义、典型模型和条件判断，避免基础知识在题型变化时失效。

  • 基本定律与典型模型
  • 实验、图表、单位与数量级
  • 公式的物理意义与适用条件
  • 条件变化后的判断与计算

读得出条件，也写得出推导。

以 EJU / 共通考试级别的高中物理为基础，对照目标大学历年真题，补充校内考常见的数学方法、长文读解与记述训练。高中物理仍是核心，只是把已经学过的内容重新组织得更深、更连贯。

  • 微小量、一次近似、无量纲化与极限
  • 用微积分重新理解高中物理公式
  • 数列、递推关系在物理过程中的应用
  • 三角恒等变换与驻波等波动问题
  • 简谐运动模型：弹簧、单摆、浮体、LC 等
  • 分子运动论、高斯定理与长文推导专题

报考规划

读懂学校的选拔逻辑，再设计报考方案。

同一份成绩，在不同大学、不同选拔方式中的价值并不相同。报考规划首先拆解各校评价结构，再判断学生的强项究竟在哪些学校、哪些环节能够转化为真正的优势。

逐校拆解评价结构

不只确认“能不能报”，还要看这所学校究竟在哪个环节拉开差距，以及学生是否适合在这个环节竞争。

  • 书类审查高中成绩、语言成绩、志望理由等，是资格门槛还是实质评分项
  • 校内考考试科目、配点、题型与难度，能否成为主要得分点
  • 面试 / 口试专业追问、口头试问的深度，以及这一环节是否具有决定性
  • EJU / 共通 / 英语最低要求、换算方式、可用科目，以及是否进入最终评价

私费外国人留学生选拔 / 一般选拔 / 共通考试利用 / SGU 英语项目 / 外部英语资格利用

让强项进入决定性评分项，让短板的影响尽可能降到最低。

志望理由与面试，必须经得起追问

文稿从学校与专业调研开始。事实和依据先成立，表达再追求简洁、准确与辨识度；最终写下的每一句话，都应当能够在面试中继续展开。

  • 调查学部、专业、课程、研究室与教授，确认具体志望依据
  • 梳理经历、兴趣、问题意识与未来方向，形成完整逻辑
  • 删除套话、重复与无效信息，提高表达密度
  • 把书面逻辑转化为口头回答，并准备可能出现的追问分支

目标是让书类有内容，面试也能用自己的语言完整说明。
