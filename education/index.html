物理教学

把分散的公式，重新连成一套物理。

我的课不会停在“这类题用这个公式”。同一个物理结构会跨章节反复出现：小振动可以出现在弹簧、单摆、浮体和 LC 回路里；驻波可以从三角恒等变换重新理解；反复加速、反复切换的过程又会自然用到数列与递推。

校内考真正拉开差距的，往往是能不能自己处理近似、补出中间推导、从长文里抓住条件，并把陌生设问还原成学过的模型。

01｜公式

公式追到来源

用微小量、极限和微积分重新看速度、能量、电磁感应等关系。知道公式怎么来，才知道条件变了以后还能不能用。

02｜结构

跨章节看同一个模型

把力学、波动、电磁学里反复出现的数学结构并排比较。学生记住的不是孤立题型，而是一套可以反复调用的模型。

03｜校内考

长文拆成条件、模型和式子

先找研究对象、过程、约束和近似，再决定用什么定律。训练的不只是最后答案，也包括推导过程和书面表达。

共通考试 / EJU：先把标准知识用准、用稳。

基本定律、典型模型和计算必须稳定，同时训练实验、图表、单位、数量级和文字条件的判断。这里追求的是基础没有明显漏洞，遇到变式也不会因为换了表述就失去方向。

  • 基本定律与典型模型
  • 实验、图表、单位与数量级
  • 公式的物理意义与适用条件
  • 条件变化后的判断与计算

校内考：在高中物理之上补“怎么推、怎么读、怎么写”。

先对照目标大学历年真题与 EJU / 共通考试的差别，再补充校内考特有的数学方法、长文读解与记述训练。重点始终放在高中物理本身，只是把学过的内容看得更深、更连贯。

  • 微小量、一次近似、无量纲化与极限
  • 用微积分重新理解高中物理公式
  • 数列、递推关系在物理过程中的应用
  • 三角恒等变换与驻波等波动问题
  • 简谐运动模型：弹簧、单摆、浮体、LC 等
  • 分子运动论、高斯定理与长文推导专题

升学规划

先看学校怎么选人，再决定怎么报。

同一组成绩，在不同学校、不同选拔方式里的价值并不一样。逐校看书类、校内考、面试 / 口试、EJU / 共通、英语资格分别怎么用，再决定报考方式、学校组合和备考顺序。

逐校拆解选拔结构

不会只看“能不能报”。更重要的是，这所学校究竟在哪个环节拉开差距，以及这个环节是不是学生的强项。

  • 书类审查高中成绩、语言成绩、志望理由等，是门槛还是重要评价材料
  • 校内考考试科目、配点、题型与难度，哪里最有拉分空间
  • 面试 / 口试是否有专业追问、准备范围，以及这一环节的重要程度
  • EJU / 共通 / 英语最低要求、可用科目，以及不同成绩的利用方式

私费外国人留学生选拔 / 一般选拔 / 共通考试利用 / SGU 英语项目 / 外部英语资格利用

笔试强，就让笔试成为优势；EJU、英语或书类更强，就优先看能充分利用这些成绩的制度。短板能避则避，避不开的部分提前补。

志望理由要经得起面试追问

先把学校和专业研究清楚，再动笔。最终写出来的内容，必须能说明“为什么是这里”，也要能在追问时继续往下讲。

  • 查学部、专业、课程、研究室和教授，找到具体的志望依据
  • 把经历、兴趣、问题意识与未来方向串成一条清楚的逻辑
  • 删掉套话和重复，让每句话都增加新的信息
  • 把书面逻辑练成口头回答，并准备可能继续追问的分支

目标是让文稿有内容，面试时也能用自己的话自然讲出来。
