物理教学

物理课程与训练内容

共通考试 / EJU 课程以高中物理范围为主，包含基本定律、典型题型、实验与图表题、单位和数量级。理工科校内考根据目标院校真题增加近似处理、微积分、数列、三角变换等内容，并安排长题干、推导和记述训练。

公式会结合现象、图像和实验说明适用条件；同一知识点的典型题与变式集中安排，便于比较题设变化对应的处理方法。

我的物理教学

把公式还原到原理，把章节连成体系。

我不希望学生只记住某一道题的解法。课堂上会说明公式的来源、物理意义和适用条件，也会把不同章节中反复出现的结构放在一起看。

弹簧、单摆、浮体和 LC 回路可以从简谐运动的共同结构理解；驻波会结合三角变换重新推导；重复过程会联系数列与递推。理工科校内考部分则根据目标院校真题补充近似、微积分、长题干和书面推导。

报考规划

本科报考与选拔方式

根据当前成绩、目标专业、可用考试成绩和备考时间，逐校整理材料审查、校内考、面试 / 口试，以及 EJU、共通考试和英语成绩的要求与计分方式。

院校选拔方式与配点

  • 书类审查高中成绩、语言成绩、志望理由等，是资格门槛还是实际评分项
  • 校内考考试科目、配点、题型与难度，能否成为主要得分点
  • 面试 / 口试专业追问、口头试问的深度，以及这一环节在最终评价中的权重
  • EJU / 共通 / 英语最低要求、换算方式、可用科目，以及是否进入最终评分

私费外国人留学生选拔 / 一般选拔 / 共通考试利用 / SGU 英语项目 / 外部英语资格利用

报考方案根据目标专业、现有成绩、考试日程和各项成绩的计分方式确定。
