教学方法与题型组织

课堂会说明公式的来源、物理意义和适用条件，把同一知识点的典型题和变式集中讲解。弹簧、单摆、浮体与 LC 回路可从简谐运动的共同结构理解；驻波与三角变换、重复过程与数列递推可联系起来学习。

校内考根据目标校历年真题，练习条件提取、近似处理、推导步骤和规范书写。

共通考试 / EJU 物理

课程系统整理基本定律与典型题型，并训练实验、图表、单位、数量级、文字条件和常见综合题。

  • 基本定律与典型模型
  • 实验、图表、单位与数量级
  • 公式的物理意义与适用条件
  • 条件变化后的判断与计算

理工科校内考物理

根据目标院校历年真题补充近似处理、微积分、数列、三角变换等常用方法，并训练长题干、推导过程和规范书写。

  • 微小量、一次近似、无量纲化与极限
  • 用微积分重新理解高中物理公式
  • 数列、递推关系在物理过程中的应用
  • 三角恒等变换与驻波等波动问题
  • 简谐运动：弹簧、单摆、浮体、LC 等
  • 分子运动论、高斯定理与长文推导专题

报考规划

本科报考与选拔方式

根据当前成绩、目标专业、可用考试成绩和备考时间，逐校整理材料审查、校内考、面试 / 口试，以及 EJU、共通考试和英语成绩的要求与计分方式。

院校选拔方式与配点

  • 书类审查高中成绩、语言成绩、志望理由等，是资格门槛还是实际评分项
  • 校内考考试科目、配点、题型与难度，能否成为主要得分点
  • 面试 / 口试专业追问、口头试问的深度，以及这一环节在最终评价中的权重
  • EJU / 共通 / 英语最低要求、换算方式、可用科目，以及是否进入最终评分

私费外国人留学生选拔 / 一般选拔 / 共通考试利用 / SGU 英语项目 / 外部英语资格利用

报考方案根据目标专业、现有成绩、考试日程和各项成绩的计分方式确定。

志望理由・面试・理科口试

根据目标学部、学科、课程、研究室与教授信息整理志望理由，并结合本人经历准备面试追问和专业口试。书面材料与现场回答保持事实和志望方向一致。

  • 调查学部、专业、课程、研究室与教授
  • 整理经历与志望方向之间的具体联系
  • 删除套话、重复与无效信息
  • 准备面试中可能继续追问的分支
